# Beitragen

1. Eine kleine, klar prüfbare Aufgabe festlegen.
2. Einen eigenen Branch erstellen.
3. Kleine Änderungen passend zur Architektur umsetzen.
4. Lokal `dotnet build` und `dotnet test` ausführen und bei Godot-Änderungen die Szene starten.
5. Einen verständlichen Conventional-Commit erstellen.
6. Einen Pull Request mit Umfang, Tests und bekannten Grenzen eröffnen.
